Backend spec (basePath /, paths start with /api/v1). "Try it out" sends real requests to https://cashregister.adyl.org: log in with /api/v1/auth/login, then press Authorize and paste Bearer <access_token>.
New since last version: client id on create (records, registers, members), PATCH /cash-registers/{id} pin, created_by on registers, PATCH /companies/{id} rename, list filters, and the Replication group (local server ↔ cloud). Gone: POST /api/v1/sync is no longer listed.
